# Start Next Phase

Transition from the current phase to the next one.

Usage: `/new-phase`

Steps:
1. Run `/phase-status` to confirm all current phase deliverables are complete
2. Identify the next phase from the CLAUDE.md phase table
3. Read `docs/requirement_analysis.md` for the next phase spec
4. Create `docs/phase<N>.md` with a detailed plan (deliverables, file list, acceptance criteria)
5. Update the phase status table in `CLAUDE.md` — mark current ✅, next 🔄
6. List the first 3 tasks to start in the new phase
